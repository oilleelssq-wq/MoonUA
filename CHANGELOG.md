# Changelog

## 0.2.0

- Added QualifiedName codec.
- Added LocalizedText codec with locale/text encoding-mask combinations.
- Added reserved-bit, truncation, and known-byte-vector tests.

## 0.1.0

- Added little-endian OPC UA scalar readers and writers.
- Added nullable UTF-8 string and ByteString codecs.
- Added TwoByte, FourByte, Numeric, String, Guid, and Opaque NodeId codecs.
- Added bounds checks, length limits, typed errors, and known-byte-vector tests.
